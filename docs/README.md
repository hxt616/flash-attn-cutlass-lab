# Public docs

This directory contains the public design and tuning notes for the project:

| 文档 | 内容 |
|---|---|
| [`design.md`](design.md) / [`design_zh.md`](design_zh.md) | FA2 math, CuTe mapping, varlen, paged decode |
| [`tuning.md`](tuning.md) / [`tuning_zh.md`](tuning_zh.md) | block-N experiments, official comparison, bottlenecks |

Personal learning notes (debugging log, interview notes, detailed performance-gap
analysis) and upstream tutorial copies are intentionally kept outside the public
repository. They are not required to build or use the project.

For the project overview, start with [`../README.md`](../README.md) or
[`../README_zh.md`](../README_zh.md).
